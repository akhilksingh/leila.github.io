# Photos for the site

Put photos in this folder with exactly these names (lowercase, `.jpg`).
Each one shows up on the site as soon as the file exists.

| File name      | Where it appears                 | Best shape              |
|----------------|----------------------------------|-------------------------|
| `portrait.jpg` | Cover, centre of the first screen | Tall, about 3:4         |
| `care.jpg`     | Chapter 1, Adult care            | Tall, about 4:5         |
| `fashion.jpg`  | Chapter 2, Luxury fashion        | Tall, about 4:5         |
| `tech.jpg`     | Chapter 3, Technology and AI     | Tall, about 4:5         |
| `dream.jpg`    | Chapter 4, An Adult Family Home  | Tall, about 4:5         |

Keep each file under about 500 KB so the page loads quickly.
